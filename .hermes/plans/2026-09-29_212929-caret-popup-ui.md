# Caret Pop-up UI Implementation Plan

> **For Hermes:** Use subagent-driven-development skill to implement this plan task-by-task.

**Goal:** Make the suggestion pop-up visibly appear next to the caret on this KWin Wayland session (or
record an evidenced finding that it cannot), with the notification fallback intact and **no silent
failures** — a pop-up that fails to start must never be mistaken for one the user dismissed.

**Architecture:** The pop-up stays a separate process with the same argv-in/word-out contract
`notify-send` has, so no GTK state enters the watcher. Which window flavour is visible gets decided by
measurement first (Task 1 is a gate, not an assumption); the launcher is then hardened so every failure
mode is distinguishable (Task 3), and the winning flavour is wired in behind it (Task 6). Acceptance is
mechanical: the pop-up's own text is located by OCR and compared against the caret's real screen
coordinates from AT-SPI.

**Tech Stack:** Python 3 with `gi` (GTK3 3.24, AT-SPI), `/usr/bin/python3` explicitly (the agent's python
has no `gi`), `xdotool`, `spectacle`, `tesseract`, `magick`, systemd user units.

**The bug this plan exists to fix** (found by reading the code, not by guessing): in
`desktop/grammar-watch.py`,

```python
    if proc.returncode == 2:
        return None
    return proc.stdout.decode().strip()
```

Only exit 2 means "no pop-up possible". Every other non-zero exit — a crash, a missing GTK typelib, a
future refactor's TypeError — returns `""`, which `offer()` reads as *"the user dismissed it"*: the
suggestion is silently dropped and the text is never fixed. That is the same silent-failure class as the
original `kdialog` bug and the `can't open file` launches above.

**Tool constraints (learned the hard way):**
- The `terminal` tool refuses `&`, `nohup`, `setsid`, and shell-level backgrounding. Launch GUI probes with
  `background=true` and add `notify=true`, or run them under `timeout` in the foreground.
- Quote every path. `"/home/chethan/Documents/Default Project/..."` has a space in it.
- `pkill -f <pattern>` matches the invoking shell's own command line; it killed the shell twice. Never use
  it without a bracket trick (`'[g]tkpop'`) or without excluding `$$`.
- Verify GUI outcomes with OCR coordinates or a pixel diff, never by eyeballing a screenshot for a shape.

## Proposed approach

Three phases. **Phase 1 (Tasks 1–3):** settle *what is visible* by running the variant matrix with exit
codes and stderr captured, then fix the launcher's silent-failure hole with a test that proves the hole
existed. **Phase 2 (Tasks 4–6):** make the pop-up tell us where it landed and whether it was placed, wire
the winning flavour behind the hardened launcher, and keep the notification as the fallback. **Phase 3
(Tasks 7–10):** prove placement mechanically (OCR bbox vs caret extents), prove the click path either with
`xdotool` (X11 windows are clickable) or via the existing stub contract, then document, install, commit.

If Task 1 shows **no** flavour is visible, the plan degrades gracefully: Task 3's hardening and its test
still ship (they are pure bug fixes), the notification stays the delivery mechanism, and Task 10 records
the finding instead of a feature.

### Task 7: Prove the pop-up appears **at the caret**, mechanically

**Objective:** The acceptance test for "use pop ui": the pop-up's own text must be located by OCR within a

**Files:**

**Step 1: Write the test (skips itself where it cannot run)**

```python
#!/usr/bin/env python3
"""Acceptance: the suggestion pop-up appears next to the caret.

Skips (with a printed reason) when there is no LibreOffice, no display, or no at-spi — the same
pattern as test-watch.py's live leg, which is what keeps this runnable in CI.

Proves placement by locating the pop-up's own text with OCR and comparing it to the caret's real
screen rectangle. A screenshot is not evidence of position until something measures it.
"""
import importlib.util
import os
import shutil
import subprocess
import sys
import tempfile
import time

try:
    import gi
except ImportError:
    if not os.environ.get("GRAMMAR_TEST_REEXEC") and os.path.exists("/usr/bin/python3"):
        os.environ["GRAMMAR_TEST_REEXEC"] = "1"
        os.execv("/usr/bin/python3", ["/usr/bin/python3", os.path.abspath(__file__)] + sys.argv[1:])
    print("popup placement: skipped — no gi")
    sys.exit(0)

gi.require_version("Atspi", "2.0")
from gi.repository import Atspi  # noqa: E402

HERE = os.path.dirname(os.path.abspath(__file__))
UNIT = "popup-place-test"
PROFILE = os.path.join(tempfile.gettempdir(), "grammar-watch-test-profile")
BAD = "She go to the office."
checks = []


def ok(condition, message):
    checks.append(message)
    assert condition, message


def load(name, filename):
    spec = importlib.util.spec_from_file_location(name, os.path.join(HERE, filename))
    module = importlib.util.module_from_spec(spec)
    spec.loader.exec_module(module)
    return module


watch = load("grammar_watch", "grammar-watch.py")


def find_app(sub):
    desktop = Atspi.get_desktop(0)
    for i in range(desktop.get_child_count()):
        app = desktop.get_child_at_index(i)
        if app is not None and sub.lower() in (app.get_name() or "").lower():
            return app
    return None


def document(app, depth=0):
    if app is None or depth > 16:
        return None
    try:
        if app.get_role_name() == "paragraph" and app.get_editable_text_iface() is not None:
            return app
    except Exception:
        pass
    try:
        for i in range(min(app.get_child_count(), 300)):
            found = document(app.get_child_at_index(i), depth + 1)
            if found is not None:
                return found
    except Exception:
        pass
    return None


def main():
    if not (os.environ.get("DISPLAY") or os.environ.get("WAYLAND_DISPLAY")):
        print("popup placement: skipped — no display"); return 0
    if not (shutil.which("soffice") and shutil.which("spectacle") and shutil.which("tesseract")):
        print("popup placement: skipped — need soffice, spectacle and tesseract"); return 0
    subprocess.run(["systemctl", "--user", "reset-failed", UNIT], capture_output=True)
    shutil.rmtree(PROFILE, ignore_errors=True)
    subprocess.run(["systemd-run", "--user", "--unit", UNIT, "--collect", "soffice", "--writer",
                    "--norestore", "--nologo", "-env:UserInstallation=file://" + PROFILE],
                   capture_output=True)
    try:
        doc = None
        for _ in range(45):
            time.sleep(1)
            doc = document(find_app("soffice"))
            if doc is not None:
                break
        if doc is None:
            print("popup placement: skipped — LibreOffice never appeared on the a11y bus"); return 0
        component = doc.get_component()
        for _ in range(20):                     # KWin keeps focus with the window the user clicked
            if component is not None:
                Atspi.Component.grab_focus(component)
            time.sleep(0.5)
            if doc.get_state_set().contains(Atspi.StateType.FOCUSED):
                break
        if not doc.get_state_set().contains(Atspi.StateType.FOCUSED):
            print("popup placement: skipped — the window manager kept focus"); return 0
        editable = doc.get_editable_text_iface()
        text = doc.get_text_iface()
        editable.delete_text(0, Atspi.Text.get_character_count(text))
        editable.insert_text(0, BAD, len(BAD))
        time.sleep(2.0)                        # debounce (1.2s) plus the engine round trip
        caret = Atspi.Text.get_caret_offset(text)
        rect = Atspi.Text.get_character_extents(text, max(0, caret - 1), Atspi.CoordType.SCREEN)
        shot = os.path.join(tempfile.gettempdir(), "popup-place.png")
        subprocess.run(["spectacle", "-b", "-n", "-f", "-o", shot], capture_output=True, timeout=60)
        time.sleep(1)
        words = []
        out = subprocess.run(["tesseract", shot, "stdout", "tsv"], capture_output=True, timeout=120)
        for line in out.stdout.decode().splitlines()[1:]:
            parts = line.split("\t")
            if len(parts) == 12 and any(k in parts[11].lower() for k in ("goes", "fix", "copy")):
                words.append((int(parts[6]), int(parts[7]), parts[11]))
        ok(bool(words), "the pop-up's own text is on screen (OCR found %r)" % (words or None))
        if words:
            x, y, _ = min(words, key=lambda w: w[0])
            ok(abs(x - rect.x) < 400 and abs(y - rect.y) < 400,
               "and it is near the caret (popup %d,%d vs caret %d,%d)" % (x, y, rect.x, rect.y))
        print("popup placement: %d assertions - passed" % len(checks))
    finally:
        subprocess.run(["systemctl", "--user", "stop", UNIT], capture_output=True)
    return 0


if __name__ == "__main__":
    sys.exit(main())
```

## Risks, tradeoffs, and open questions

1. **No flavour may be visible, and that outcome is allowed.** X11 is measured-invisible already; Wayland
   `POPUP_MENU` is untested. If Task 1 finds nothing visible, Tasks 3, 9 and 10 still ship (the bug fix,
   the docs, the record) and the pop-up is shelved with evidence. Do not "fix" this by trying more window
   hints — hints have been tried; a different mechanism would be needed.
2. **Wayland gives clients no absolute positioning.** Even in the best case the pop-up may land where the
   compositor chooses (KWin's smart placement tends to use the pointer). Task 4's `PLACED` line is what
   makes that honest instead of surprising; the README must say which one it is.
3. **A pop-up that steals focus is worse than no pop-up.** `set_accept_focus(False)` is already set, and
   the X11 flavours also use `POPUP_MENU`. Task 7 types into a document and then asserts placement — if
   focus were stolen, the LibreOffice caret assertion would still pass but typing would be interrupted, so
   keep the assertion that the document text was unchanged before the click (Task 8 reads it first).
4. **The notification path must not be weakened.** `ask()` falls back only when `popup_actions` returns
   `None`. After Task 3 that is every failure, which is the point — but it means a pop-up that opens and is
   *dismissed* returns `""` (not `None`) and correctly does **not** trigger a toast. Preserve that
   distinction: `None` = could not ask, `""` = asked and dismissed.
5. **`xdotool` only sees X11 windows.** If the visible pop-up is Wayland-native, the click path cannot be
   driven from outside without input synthesis, which this box lacks (`wtype` reports no virtual-keyboard
   protocol; `ydo​toold` is not running; `/dev/uinput` is root-only). The stub contract stays the coverage
   for Fix/Copy in that case — say so in the test output rather than implying it was clicked.
6. **Open question:** should the pop-up auto-dismiss while the user keeps typing? Currently it lives 12s
   and ignores further keystrokes. If Task 7 shows it lingering over text, shortening the timeout is a
   one-line change — but do not guess; measure the annoyance first.
